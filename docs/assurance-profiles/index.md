# Assurance profiles

Assurance Profiles define **upper-level Targets** that are not owned by an individual Requirement or Technical requirement. They complement, and never replace, Requirement/TREQ {doc}`Verification profiles <../verification-profiles/index>`.

The project-wide {ref}`Test Plan <test-plan-upper-level-assurance>` defines the allowed assurance kinds, ownership rule, status semantics, and completion policy. A branch profile declares only the concrete Feature/Goal/Product-System integration and validation criteria required for that branch.
