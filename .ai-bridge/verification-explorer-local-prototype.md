# Verification Explorer local prototype ledger

Scope: fast UX iteration in **llm-router only**. Nothing in this file is accepted Ternforge infrastructure yet.

## Rules for this prototype

- Prefer changes that are reversible in minutes.
- Do not propagate to DocOps, py-testkit, template-components, or other consumers until the UX is accepted.
- Every local shortcut must be listed below with its intended owner if accepted and cleanup action if rejected.
- The explorer judges nothing a monitor does not judge: statuses come from the same domain algebra as Contract Evidence and the Health Map, causes from the Health Map's own words; no second source of truth.
